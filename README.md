##Sobre o projeto

Um site simples informativo desenvolvido como projeto acadêmico de UI/UX, focado em ajudar jogadores de todos os níveis a entender melhor o sistema de itens do League of Legends.

O site foi feito com somente com:

HTML -> Estrutura semântica <br>
CSS -> Estilização <br>
GITHUB -> Versionamento <br>
