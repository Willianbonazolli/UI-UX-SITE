Sobre o projeto

O site Itens do LoL foi criado como um projeto acadêmico com o objetivo de facilitar o entendimento dos itens do League of Legends para jogadores iniciantes.

Muitas vezes novos jogadores têm dificuldade em entender quais itens comprar e quando utilizá-los. Este projeto busca simplificar essas informações de forma clara e direta.

O que pode gerar situações engraçadas, como o famoso jungle diff.

O que explicamos?

Abordamos desde atributos básicos (AD, AP, Letalidade) até as passivas únicas e itens míticos/lendários, categorizando-os por classe de campeão para facilitar a busca.

No LoL, os itens são a forma como você escala o poder do seu campeão. Um item comprado errado pode custar uma vantagem na rota. Nosso site foca na adaptabilidade: ensinar o jogador casual a olhar para o time inimigo e escolher a melhor defesa ou o melhor ataque.

Este projeto foi desenvolvido como parte de um estudo de UI/UX e Desenvolvimento Web, focando em uma interface limpa,intuitiva e que não sobrecarregue o usuário com informações desnecessárias.
